# Практична робота: Перехоплення всіх винятків, обробка винятків за типом та умовою

**Тема:** Перехоплення всіх винятків, обробка винятків за типом та умовою в C#  
**Мета:** Навчитися розпізнавати виняткові ситуації в програмі, перехоплювати їх за допомогою конструкції `try-catch`, зокрема загальним блоком `catch (Exception)`, аналізувати об'єкт винятку, виконувати завершальні дії в блоці `finally`, а також обробляти винятки окремо за типом і за умовою за допомогою кількох блоків `catch` та фільтрів `when`, на прикладі консольного застосунку для введення чисел з клавіатури.

---

## Опис проекту та реалізація

У проекті реалізовано консольну програму на C# (.NET), яка:
1. Запитує у користувача введення цілого числа за допомогою `Console.ReadLine()`.
2. Використовує метод `Int32.Parse(input)` для перетворення рядка в число (без використання `TryParse`).
3. Використовує захищений блок `try-catch-finally`:
   - `catch (ArgumentNullException)` — обробка ситуації `null` (наприклад, комбінація Ctrl+Z);
   - `catch (FormatException)` — введення нечислових символів або дробових чисел;
   - `catch (OverflowException) when (...)` — вихід за межі діапазону типу `int` (окремо для від'ємних і додатних чисел за допомогою фільтра `when`);
   - `catch (Exception)` — перехоплення будь-яких інших непередбачуваних помилок;
   - `finally` — обов'язковий блок, що сигналізує про завершення поточної спроби.
4. Знаходиться в циклі `while (!isCorrect)` і продовжує запитувати число доти, доки користувач не введе коректне значення.
